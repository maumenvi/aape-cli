# Getting Started (CLI)

## Requisitos

- Node.js >= 26

## Instalacao

```bash
npm install -g @maumenvi/aape
```

## Fluxo rapido

```bash
aape init
aape skills find react
aape mcp find filesystem
aape lock
aape verify
```

## Atualizar CLI local (repo)

Se estiver desenvolvendo no repo local:

```bash
aape-update-local /home/marco/Documentos/projetos/aape-cli
```
